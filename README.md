# Agna_Shakosh
Full-stack marketplace platform for buying, selling, and renting tools and equipment. Includes a workers section for plumbers, electricians, carpenters, etc., allowing users to connect and communicate directly. The platform centralizes services and items to make access easier, faster, and more organized.
🚀 Features
🛒 Buy, sell, and rent tools & equipment
🧰 Equipment categories (rent / sell / both)
👷 Workers directory (plumbers, electricians, carpenters, etc.)
💬 Direct communication between users and workers
🔍 Search system for tools and services
📦 Full-stack architecture (Frontend + Backend)
